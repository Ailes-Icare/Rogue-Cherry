# Contexte Développeur

> Ce fichier donne à l'IA le contexte sur l'utilisateur. À personnaliser selon tes préférences.

## Qui suis-je

- **Développeur autodidacte**, pas de formation formelle en code
- Expérimenté en informatique depuis l'enfance, mais pas en programmation structurée
- Je travaille **seul**, pas d'équipe
- Je suis passé du **vibe coding** au **Spec-Driven Development** pour garder le contrôle absolu de mes projets

## Mon niveau technique

- **JavaScript / React / Tailwind** : C'est le nouveau cœur de cible de la stack technique. L'IA gère la complexité technique (Hooks React, architecture des composants, subtilités de Tailwind), mais elle doit m'expliquer de manière claire les choix qu'elle fait.
- **Concepts** : Je connais la logique algorithmique de base (variables, conditions, boucles, fonctions). J'ai besoin de l'IA pour transposer cela proprement dans la philosophie déclarative de React (ex: utiliser `map()` dans du JSX, conditionner l'affichage, gérer le cycle de vie).
- **Git** : Usage basique (commit, push)

## Comment travailler avec moi

- **Langue** : Français. Documentation, commentaires, et échanges exclusivement en français.
- **Pas de jargon inutile** : Si un concept technique React (comme le DOM virtuel, la mémorisation avec `useMemo`, le Context API) est absolument nécessaire, l'expliquer brièvement et de façon très pragmatique.
- **Analogies** : Les analogies du monde réel m'aident beaucoup à comprendre les concepts abstraits du développement frontend.
- **Validation systématique** : Me consulter sur TOUTE décision architecturale (création de gros composants, ajout de librairies externes, gestion d'état complexe). Je veux maintenir la cohérence de l'interface moi-même.
- **Petits détails techniques** : L'IA peut les gérer sans demander (classes Tailwind classiques, alignements, gestion des imports, destructuration des props).
- **Honnêteté absolue** : Ne jamais mentir sur l'état de l'interface ou du code. Si un composant ne marche pas, ou si le rendu visuel est cassé, le dire clairement.

- **OS** : Windows 11 Pro
- **Capacité** : Peut faire tourner des serveurs de développement Vite ultra rapides, de l'IA locale de haute capacité (grâce aux 24 Go de VRAM de la RTX 3090), et traiter n'importe quel projet ambitieux sans aucun souci d'espace ou de puissance locale.

## Méthodologie

J'utilise le **Spec-Driven Development (SDD)** :
1. Les specs (incluant l'UI/UX) sont la source de vérité (pas le code).
2. Rien n'est codé (aucun composant généré) sans une spec validée.
3. Changements minimaux uniquement (on ne recrée pas l'architecture pour corriger une marge).
4. Audits réguliers de cohérence visuelle et logique.
5. Tout est documenté en français.
