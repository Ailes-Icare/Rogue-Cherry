# RULE STORY V8 — Bouton "New Branch" Responsive

## Contexte
Le bouton "New Branch" n'était pas très gracieux quand on le forçait à se réduire en taille (responsive). La distance entre le logo et le texte était fixe (espaces). 
Il a été repensé pour être fluide et s'adapter proprement.

## UI / UX MANDATORY
- Le logo et le texte sont deux blocs distincts.
- La marge entre la gauche du texte, l'espace entre les deux éléments, et la droite du logo est la même et dynamique.
- Le texte se mettra sur une double ligne au besoin.
- Le logo restera "grand" le plus longtemps possible, mais si la place finit par être trop réduite, alors il est caché. 
- Si la place est trop réduite pour le texte, alors le logo réapparaît et remplace le texte.

## Précision ultérieure : Tailles de texte
- Taille de police maximale : 18px
- Taille de police minimale : 14px (en deçà, le texte disparaît pour laisser place à l'icône).
