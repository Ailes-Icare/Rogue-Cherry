================================================================================
PARTIE 3 : SCÉNARIO DE TEST DE CONFLIT ET SMART CANCEL (Annulation Impossible)
================================================================================

--------------------------------------------------------------------------------
CONSIGNE DU TEST :
1. Importez le fichier "texte d'exemple.md" (V1.0.0).
2. Copiez et appliquez successivement les requêtes ÉTAPE 1, ÉTAPE 2 et ÉTAPE 3 ci-dessous dans l'ordre (en les collant l'une après l'autre via 'Coller REQUÊTE'). Votre historique montera jusqu'à la version V1.0.3.
3. Dans la Sidebar droite (Time-Travel), sélectionnez l'étape 2 (NAV-BOOST, version V1.0.2).
4. Cliquez sur le bouton "Construction intelligente d'une requête d'annulation" (⚙️↩️) de cette version.
5. CONSTAT : L'application vous avertit par un popup qu'un conflit existe (l'étape 3 NAV-WARP dépend de la modification apportée par l'étape 2) et insère un record d'information "❌ Échec Annul." dans le tableau d'historique.
6. Cliquez sur le bouton engrenage (⚙️) à droite de cette ligne d'échec pour générer automatiquement la pile d'annulation corrective (Smart Cancel Multistack) dans votre Sidebar gauche.
7. Cliquez sur "APPLIQUER PILE" pour résoudre proprement le conflit en annulant les étapes dans l'ordre inverse et en restaurant la trajectoire initiale !
